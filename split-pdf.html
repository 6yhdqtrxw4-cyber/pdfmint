Two ways to split

  • Extract a range — type any combination like 1-3, 5, 8-12 and download one new PDF containing exactly those pages
  • Burst mode — leave the range empty and every page becomes its own downloadable PDF file

Why split on-device?

Financial statements, legal filings, and medical documents are exactly the kind of files people need to split — and exactly the kind you should never upload to a random "free PDF site". PDFMint processes everything locally with pdf-lib:

  • Files never leave your device — pull the network cable to prove it
  • No sign-up, no watermark, no page limits
  • Original PDF is never modified; you always download new files

How to split a PDF

  • Click "Split PDF" and drop one PDF file
  • Type the pages to keep (e.g. 2-4, 9) — or leave empty to split every page
  • Press "Process → Download"

FAQ

Does splitting reduce quality?

No. Pages are copied losslessly into new files — no re-compression, no rendering to images.

Is there a page limit?

No hard limit. Documents of a few hundred pages work smoothly on typical devices.

Can I split a password-protected PDF?

If the file allows opening without a password, yes. Files that require a password to open are not supported.
