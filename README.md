# PDFMint

Privacy-first PDF tools — merge & split, 100% client-side. Files never leave the browser.

- `index.html` — tool UI
- `landing.html` — SEO landing page
- `app.js` — merge/split logic (pdf-lib)
- `vendor/pdf-lib.min.js` — vendored engine, zero external requests

Monetization plan: free core tools + optional Pro tier (batch, compression) later; AdSense once traffic arrives.
